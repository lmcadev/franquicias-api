Franquicias API

API REST desarrollada con Spring Boot para la gestión de franquicias, sucursales y productos. Permite administrar stock, operaciones CRUD y consultas específicas como el producto con mayor disponibilidad por sucursal dentro de una franquicia.

Tecnologías utilizadas

Java 21

Spring Boot

Spring WebFlux

Spring Data (MySQL)

Docker

Swagger / OpenAPI

JUnit y Mockito

Arquitectura Clean Architecture

Principios SOLID

Monolito modular

Infraestructura como código (IaC)
